# BRUGG Pipes North America: product site

Static site, published by Netlify from the `main` branch (publish directory: repository root). No build step.

## Structure

- `index.html`: overview of all eight products
- `<product>/index.html`: sub-product overview (PREMANT, CASAFLEX, CALPEX, ARMOPEX)
- `<product>/product.html`: full product page
- `<product>/docs/`: PDFs, `<product>/media/`: photos, posters and videos, `<product>/fonts/`: local fonts
- `assets/site.css`, `fonts/`, `media/`: shared by the overview and the sub-product pages

No external requests, no cookies, no tracking.
